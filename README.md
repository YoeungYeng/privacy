# MetaBot Studio - Privacy Policy

Single-page official **Privacy Policy** (with built-in Section 5: **User Data Deletion Instructions**) required by Meta for Facebook App Live Mode approval.

## Deployment to Vercel

```bash
git init
git add .
git commit -m "feat: privacy-policy.html for meta compliance"
git branch -M main
git remote add origin https://github.com/<YOUR_GITHUB_USERNAME>/<YOUR_REPO_NAME>.git
git push -u origin main
```

## Meta for Developers Form Values
- **Privacy Policy URL:** `https://<YOUR_VERCEL_DOMAIN>/privacy-policy.html` (or `https://<YOUR_VERCEL_DOMAIN>/`)
- **User Data Deletion Instructions URL:** `https://<YOUR_VERCEL_DOMAIN>/privacy-policy.html#data-deletion`
